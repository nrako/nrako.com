Some habits were never virtues. They were prices, paid because the alternative
cost more. When the alternative got cheap, the habit stayed out of loyalty.

## Stopped

- **Reusing code I did not like.** Rewriting it is now quicker than
  understanding why it was written that way.
- **Batching small fixes.** A fix that takes a minute does not need to wait
  for four others.
- **Defending a first draft.** The second one costs nothing, so the first has
  no standing.

## Kept

Reading everything that ships under my name, slowly, as if someone else had
written it. Somebody else did.
